## Descripción General

### Objetivo

El curso presenta las diferentes metodologías, estrategias y buenas prácticas para el diseño de una arquitectura de solución, examinando desde distintos niveles de abstracción las tareas que enfrenta un arquitecto de TI:

- **Primera parte del curso** — se diseña una **arquitectura de referencia** para una organización: se propone un proceso para su elaboración, sus vistas y sus principales modelos.
- **Segunda parte del curso** — la arquitectura de referencia se utiliza para diseñar **arquitecturas de solución** conformes a ella, siguiendo un principio de diseño basado en servicios.

### Metodología

El curso gira alrededor de un **proyecto de tamaño mediano** (caso de estudio), utilizado para introducir gradualmente los conceptos de arquitectura de referencia y arquitectura de solución. El estudiante debe asistir y participar activamente en las clases teóricas y desarrollar los **cuadernos de trabajo** asociados a cada tema, en grupo, a lo largo del semestre.

### Competencias a Desarrollar

- Diseñar el proceso y los modelos de una arquitectura de referencia organizacional (vista funcional, vista de integración, vistas complementarias).
- Derivar arquitecturas de solución a partir de una arquitectura de referencia, siguiendo un principio de diseño basado en servicios (ecosistemas de servicios).
- Identificar problemas de negocio y evaluar alternativas de solución antes de comprometerse con un diseño.
- Documentar y presentar formalmente una arquitectura ante audiencias técnicas y de negocio.
- Sustentar decisiones de arquitectura con análisis financiero y de viabilidad.

### Relevancia en el Currículo

Este curso es parte del núcleo de la Maestría en Arquitecturas de Tecnologías de la Información (MATI): toma los fundamentos de arquitectura empresarial y de software vistos en otros cursos del programa y los aplica al ciclo completo de diseño de una solución — desde la arquitectura de referencia organizacional hasta la arquitectura de solución orientada a servicios.

### Clonar el repositorio

```bash
git clone <url-del-repositorio>
cd mati-solution-architecture
```

### Prerrequisitos

- Un lector de PDF para el material de clase.
- Acceso a Bloque Neón con el usuario institucional Uniandes (entrega oficial de trabajos y comunicación del curso).
- [draw.io / diagrams.net](https://app.diagrams.net/) (o herramienta de diagramación equivalente) para elaborar las vistas de arquitectura.

1. Lea el programa oficial en [`contenido/intro`](contenido/intro) para entender la estructura general, el cronograma y la política de evaluación.
2. Revise el caso de estudio del proyecto (TravelHub, en [`contenido/arq-referencia/ARTI4201-202610-Proyecto.pdf`](contenido/arq-referencia)) antes de la primera sesión — es la base de todos los cuadernos de trabajo y del proyecto del curso.
3. Siga el material de `arq-referencia` en orden (introducción → vista de integración → vistas complementarias) durante las semanas 1 a 8.
4. Continúe con `arq-solucion` en orden (problema → alternativas → vista funcional → vista de integración → vistas complementarias → análisis financiero) a partir de la semana 9.
